# Frontend — AI-Powered Registration System

Vue 3 frontend for the AI-Powered Registration & Dynamic Form System.

## Tech Stack

- Vue 3
- Vite
- Vue Router
- Tailwind CSS
- Vue Draggable

## Development

```bash
npm install
npm run dev
```

The development server is provided by Vite. The frontend communicates with the FastAPI backend through REST APIs.

## Production Build

```bash
npm run build
```

For full project setup, architecture, Docker instructions, and feature documentation, see the root `README.md`.
